## 3. 真实端到端联调（FastAPI + Next.js + 阿里云百炼）

使用独立端口（8011 / 3011）与临时 SQLite 数据库，接入 `qwen3.8-flash`（`python_graph` + `native` 原生工具调用）执行完整业务闭环：

1. **首页与会话初始化**：`GET /` 与 `GET /api/conversation` 均返回 200，会话 Cookie 正常下发。
2. **真模型 SSE 多步对话**（查 `PS11752778` 价格并核验 `WSF26C3EXF01` 适配）：
   * 实时推送 **7 条 SSE 进度事件**（决策 → 读详情 → 决策 → 核验适配 → 决策 → 汇总 → 生成中文摘要）。

4. **反馈回显、指标与导出**：提交点赞后刷新 `/api/conversation` 准确回显 `{"rating": "up"}`；`/api/metrics` 与 `/api/conversation/export` 均返回 200。
