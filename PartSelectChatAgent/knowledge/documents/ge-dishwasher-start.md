# Controls and delayed start

When lights work but a cycle does not begin, check whether control lock, delayed start or demonstration mode is enabled. Unlock instructions vary by model: consult its manual rather than applying a universal button sequence.

# Door closure and service

An obstruction around the door can prevent the latch from engaging. Check that the door closes normally without forcing it. If these basic checks do not resolve the problem, arrange service. This article does not identify a replacement latch or prove part compatibility.
